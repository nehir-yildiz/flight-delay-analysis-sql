# Mini Project: Flight Delays Analysis

## Overview
This project is a **Java-based database application** that analyzes flight delay data using **SQL**. It connects to a PostgreSQL database and executes multiple queries to extract insights about airlines, airports, and delays.

The project demonstrates:
- **Java JDBC** for database connectivity
- SQL queries for data analysis
- Reading CSV files and batch insertion into tables
- Handling relational data with foreign keys

---

## Features / Queries
1. **Top 5 airlines with the fewest delays**  
2. **Top 5 states with the most delays**  
3. **Top 3 airports with the highest departure delays in May**  
4. **Flights over 1500 miles with departure delays over 4 hours**  
5. **States with most intra-state flights delayed over 2 hours**
